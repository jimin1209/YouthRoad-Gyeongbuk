TASK33 – 탐색 탭 상단 검색/필터/카테고리 구조 단순화

[배경]
- 탐색 탭 상단에 다음 요소들이 한 번에 섞여 있어 UI가 난잡하다.
  - 검색창
  - 모드 버튼: 전체 / 내 지역(경북 상주시) / 검색
  - "다른 지역 선택" 버튼
  - 상태 필터: 진행중만 / 마감 포함 / 마감만
  - 카테고리 칩: 취업 / 창업 / 주거 / 교육 / ...
- 사용자 입장에서 "어디를 볼지(지역)", "무엇을 찾을지(검색/카테고리)", "어떤 상태만 볼지(진행/마감)"가 구분되지 않아 직관성이 떨어진다.

[목표]
1) 탐색 탭 상단을 기능별로 3층 구조로 단순화한다.
   - 1층: [지역/모드 선택] (전국 / 내 지역 / 다른 지역)
   - 2층: [검색/카테고리] (검색창 + 추천 키워드 칩)
   - 3층: [상태 필터] (진행중만 / 마감 포함 / 마감만)
2) 최상단에는 꼭 필요한 요소만 두고,
   나머지 고급 옵션은 "필터 시트" 등으로 빼서 한눈에 보기 좋게 만든다.

[수정 범위(후보)]
- lib/features/policy_new/presentation/explore/policy_explore_screen.dart
- 상단 검색/필터/카테고리 관련 위젯들:
  - _SearchBar, _ModeSelector, _StatusFilterChips, _CategoryChips 등

[구체 작업]
1) 상단 레이아웃 그룹 재구성
   - 아래와 같은 순서로 위젯을 재배치한다.

   (1층) 모드/지역
   - "전체" / "내 지역" / "다른 지역" 세 버튼만 배치
   - 현재 선택된 모드는 강조 스타일 적용
   - "다른 지역" 선택 시 별도의 BottomSheet/전체화면으로 지역 선택

   (2층) 검색/카테고리
   - 전체 폭 검색창 1개 (placeholder: "검색어를 입력하거나 태그를 선택해보세요.")
   - 검색창 아래에 추천 키워드 칩 3~5개 (청년, 창업, 주거 등)

   (3층) 상태 필터
   - 진행중만 / 마감 포함 / 마감만 세 칩을 한 줄에 배치
   - 기본값은 "진행중만", 나머지는 토글형 단일 선택.

2) 덜 중요한 옵션은 시트로 이동
   - 필요하다면 "필터" 버튼을 우측에 하나 두고,
     고급 필터(지역 상세, 분야 다중 선택 등)는 BottomSheet로 이동시킨다.
   - 탐색 기본 화면에서는 필수 UI만 노출되도록 한다.

3) 스타일 일관성 정리
   - 상단 탭(추천/탐색/보관함)과 버튼/칩의 색상·둥근 정도를
     기존 디자인 시스템과 맞춘다.
   - iOS/Android에서 모두 한 줄 높이/간격이 과도하게 늘어나지 않도록
     padding/margin 값을 정리한다.

[Acceptance Criteria]
- 탐색 탭 상단을 한 번에 봤을 때:
  - "전국 vs 지역" 모드 / "검색/키워드" / "진행/마감 상태"가 직관적으로 구분된다.
- 불필요하게 많은 버튼이 한 줄에 섞여 보이지 않고,
  주요 동작을 이해하는 데 2~3초 이내로 충분하다.
- 기존 정책 목록/필터 기능은 동일하게 동작하되,
  상단 UI만 단순해진다.
